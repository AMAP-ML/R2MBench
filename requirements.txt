# Install example:
#   python -m pip install -r full_eval/requirements.txt
#
# External source repositories are intentionally not listed as pip packages.
# They are vendored (code only) into full_eval/third_party/ by the r2mbench
# setup script and imported via sys.path / PYTHONPATH:
#   - full_eval/third_party/Bag-of-Queries      (BOQ_ROOT,  `from boq import BoQ`)
#   - full_eval/third_party/MutualVPR           (MUTUALVPR_ROOT)
#   - full_eval/third_party/LightGlue           (LIGHTGLUE_ROOT)
#   - full_eval/third_party/GroundingDINO       (GROUNDINGDINO_ROOT, compiled _C)
#   - full_eval/third_party/sam2                (SAM2_ROOT, compiled _C)
#   - full_eval/third_party/clip                (openai/CLIP, imported via PYTHONPATH)
#   - full_eval/third_party/Omni-WorldBench-V2  (optional, --enable_worldbench_metrics)
#
# GroundingDINO and sam2 need a compiled CUDA `_C` extension. r2mbench compiles
# them from source (needs nvcc / CUDA_HOME) and also keeps the prebuilt .so as a
# fallback. Install everything from a fast PyPI mirror (github.com / pypi.org and
# the download.pytorch.org CDN may be blocked or throttled):
#   python -m pip install -r requirements.txt \
#       --index-url https://pypi.tuna.tsinghua.edu.cn/simple
#
# Some internal/non-public modules may need to be provided separately:
#   - async_batch_client, used lazily by full_eval/vlm_eval.py in OpenAI SDK mode.
